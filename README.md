# Análisis de Ventas

## Autor
Nahuel Sandoval

## Descripción
Este proyecto realiza un análisis de ventas utilizando Python.

## Funciones
- Leer un archivo CSV
- Calcular ventas totales
- Detectar el producto más vendido
- Generar un gráfico de barras

## Herramientas usadas
- Python
- Pandas
- Matplotlib
- Visual Studio Code
